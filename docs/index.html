Questions

Good to know.

Is Maho on the Play Store?

Not yet. Maho is distributed as a direct APK for now. The file on this page is a signed release build, so Android will install it after you allow installs from your browser or file manager.

Do I need an account?

No. There is no login, no cloud sync and no server owned by Maho. Your folders, items and price history live in a local Room database on your device.

How does it find prices?

Maho fetches the product page on your phone and reads structured data, meta tags and store-specific markup. Some stores block bots or render prices with JavaScript; for those, Maho falls back to a hidden WebView, and you can always set a price manually.

Why does it need internet access?

Only to load the pages and product images you save, and to check prices in the background. Nothing is sent to us — there is no “us” server to send it to.

How often are prices checked?

Every 6 hours by default. You can choose 1, 3, 6, 12 or 24 hours in Settings, or run a check immediately.

What happens if I uninstall the app?

Android removes the app's local database along with it. Maho has no cloud backup, so export anything you want to keep first. Bill export is a good way to snapshot a folder.
